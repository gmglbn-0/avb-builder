Pixel Bootloader & Custota Setup

  1. Generate / Prepare avbroot Keys:

    Ensure your avb.key, ota.key, and ota.crt are placed inside data/keys/. You should also have avb_pkmd.bin generated via avbroot pkmd generate.

  2. Initial Flash & Bootloader Locking:

    Boot into fastboot mode. Flash your custom key into hardware root of trust:
    fastboot flash avb_custom_key avb_pkmd.bin (Pixel 4)
    Then lock bootloader: fastboot flashing lock.

  3. Install Custota App:

    Flash the Custota Magisk / KernelSU module. Once booted into EvolutionX, open Custota and tap Settings.

  4. Set OTA Server URL:

    In Custota, enter the server URL: http://100.64.0.131:8085. Custota will query /{device}.json and stream signed updates directly to your phone!
